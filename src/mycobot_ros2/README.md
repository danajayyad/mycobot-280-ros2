# mycobot_ros2 #
![OS](https://img.shields.io/ubuntu/v/ubuntu-wallpapers/noble)
![ROS_2](https://img.shields.io/ros/v/jazzy/rclcpp)



This package is the **main ROS 2 package** for the MyCobot 280, intended to include nodes, controllers, and other ROS 2 functionality.  

It depends on the **`mycobot_description`** package for the robot URDF and meshes.

---

## Features

- Placeholder for ROS 2 nodes controlling MyCobot 280  
- Designed to integrate with the **robot description
